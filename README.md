# claude-agent-roles

**Six agent roles for teams that run their AI work on Claude Code (Anthropic only).**

| Role | What it does |
|---|---|
| Chief of Staff | Keeps the one list of decisions for the human owner, with a recommendation for each. |
| Account Manager | Holds the context of one account and runs its project managers. |
| Personal Assistant | An Account Manager for the owner's own inbox: drafts replies, never sends without approval. |
| Project Manager | Plans and orchestrates one project; workers do the building. |
| Task Worker | Builds one scoped task, test-first. |
| Researcher | Read-only investigation: finds facts and options with sources, changes nothing. |

Each role will ship in two formats: Claude Code agents (`.claude/agents/<role>.md`) and Paseo agent profiles.
